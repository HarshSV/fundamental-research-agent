# Navrist ratio contract (formula version `2026.10.18`)

Generated from `tools/ratio_contract.SPEC` and `tools/fundamental_ratio_registry.RATIOS`. **There is exactly one implementation of each formula** (`tools/ratio_contract.py`); the document-analysis engine, the `nse_xbrl` dashboard endpoints and the canonical `/api/v1/ratio/{key}` API are adapters over it.

## Pipeline

```
Annual Report (PDF)
  -> extraction (tools/annual_report_financials.py: narrow parser, broad alias fallback, text-disclosure scan)
  -> normalized FactSet (tools/fundamental_fact_store.py: value, prior value, period, basis, perimeter, page, method, status, confidence, warnings)
  -> integrity checks (balance-sheet identities, EPS x shares vs profit, debt <= assets)
  -> ratio contract (tools/ratio_contract.py: unrounded value_raw, status/confidence inheritance, warnings)
  -> adapters (legacy fetch shape / document rows / canonical API) -> stored rows (formula_version, computed_at) -> UI
```

## Statuses

`verified` - from disclosed inputs, no caveat. `needs_review` - computed, but an input is a proxy/estimate, a perimeter is ambiguous, an acquisition distorts comparability, or a parent is needs_review. `not_meaningful` - the arithmetic exists but is economically meaningless (negative FCF multiple, growth <= 0 in PEG ...); the number is kept but never shown as a normal multiple. `insufficient_data` / `not_disclosed` - an input is unknown; **never converted to 0**. `not_applicable` - the ratio does not apply (e.g. net-cash company for Net Debt/EBITDA, non-bank for bank ratios).

## Navrist policies

- **Statement basis** - consolidated first; standalone only when the filing has no consolidated statements. Every fact records its basis; a result can never mix bases.
- **EBIT** = Profit Before Tax + Finance Costs (other income included). **EBITDA** = EBIT + Depreciation, Amortisation & Impairment (other income included in both).
- **Total Debt** = borrowings (non-current + current + current maturities) + lease liabilities (basis 1) + debt-like other financial liabilities that pass the Three-Part Test. A lease line that was not extracted is *unknown*, flagged, and never labelled 'included'.
- **Total Liabilities** = the statement's own subtotal when it passes the balance-sheet identity; else Total Assets - (Owners' Equity + NCI). Never Total Assets - Owners' Equity when NCI exists.
- **Net Fixed Assets** = PPE + Right-of-use assets + Capital WIP + Intangible assets (goodwill excluded).
- **EPS for valuation** = Basic EPS attributable to owners (the 'excluding NCI' line when two are printed; otherwise the single printed Basic EPS per Ind AS 33).
- **Dividends** - Dividend Payout uses dividends *paid* (cash-flow statement); Dividend Yield uses DPS = interim/special declared during the fiscal year + final recommended for it. Unknown is unavailable; only an explicit 'no dividend' statement supports a zero.
- **Perimeters** - ROE, EPS ratios, payout: owners. NPM and ROA: owners' profit (approved policy, switchable via `PERIMETER_POLICY`). Whole-entity flows (OCF/Net Profit, D/E, Financial Leverage, ROIC, Beneish TATA) use whole-entity (incl. NCI) denominators/numerators.
- **Methodology** - Sr 1 Inventory Turnover = COGS / Avg Inventory (corrected 2026.10.7); Sr 8 Working Capital Turnover = Net Sales / Average Working Capital (corrected 2026.10.8 to the authoritative 68-ratio specification; the earlier closing-WC alignment is retired). Sr 31 Days Working Capital also uses average WC.
- **Acquisition-affected years** - when a material subsidiary was consolidated part-way through the year (goodwill/NCI/total-asset jump plus business-combination text), balance-vs-flow ratios are flagged needs_review. Nothing is adjusted.
- **DSCR** - Net Operating Income (EBITDA proxy, flagged) / (gross principal repayments + interest due); unavailable when gross repayments are not disclosed.
- **Beta** - weekly returns vs Nifty 50, 2 years, >= 52 observations, sample covariance/variance (ddof=1); manual document mode reports insufficient_data.
- **Free Float** - 100% - promoter % - locked-in % when locked-in shares are disclosed; otherwise a labelled proxy (needs_review). Unknown promoter holding is not assumed to mean 100%.
- **Bank/NBFC ratios (Sr 58-65)** - computed only for sectors Banks/NBFC from the dedicated bank extraction; every value passes plausibility bounds (`BANK_BOUNDS`) or is withheld.

## Final policy decisions (2026-10 final validation)

Each of these is an explicit, tested decision - not implicit implementation behaviour.

| | Decision |
|---|---|
| A | **Dividend payout (Sr 47)** = dividends actually *paid in the year to the company's own shareholders* ÷ owners' PAT - one perimeter (owners) on both sides. The cash-flow 'Dividend paid' line is a whole-entity total (parent's dividends + subsidiaries' dividends to their minorities), so it is split by recipient: owners' dividends from the reserves / equity-statement note ('Equity share ... dividend paid (cur) (prior)'), minorities' share from the NCI note ('NCI share of dividend' / 'dividend paid to non-controlling interests'); the split is reconciled to the cash-flow total (`dividend_components.reconciles`). If only the minorities' share is printed owners = total − NCI; if neither is printed on a consolidated entity with material NCI the whole-entity total is used and the ratio is `needs_review` with a perimeter warning (never presented as owners-only). It is cash-basis: prior-year dividends paid during the year are included (ANURAS FY26: the FY25 interim of ₹0.75/share = ₹8.54 Cr). The dividend declared FOR the year (DPS × shares ÷ owners' PAT) is carried as `reference_declared_for_year_payout_pct`, not as the metric. Retention (Sr 48) = 100 − payout and Sustainable Growth (Sr 49) = ROE × retention inherit the owners perimeter and status. When no paid figure exists a flagged estimate from declared DPS × shares is used; otherwise unavailable (never 0). |
| B | **NPM and ROA** use owners-attributable profit (`PERIMETER_POLICY`, one-line switch). |
| C | **Contribution margin** is always an estimated proxy (`needs_review`, confidence 0.6) and unavailable when variable costs cannot be identified (goods cost alone is not variable cost). Never `verified`. |
| D | **Altman retained earnings** = Other Equity proxy, always `needs_review`. |
| E | **Sr 1 Inventory Turnover** = Cost of Goods Sold ÷ Average Inventory. COGS = cost of materials consumed + purchases of stock-in-trade + changes in inventories (the P&L's own cost lines). *Formal correction in 2026.10.7*: the earlier Net-Sales numerator (Annual Report's own definition) is retired on the user's explicit instruction; Sr 2 Inventory Days (365 ÷ turnover) and Sr 9 Cash Conversion Cycle follow automatically. The XBRL fallback computes it through the same contract. |

| J | **Lenders (sector Banks / NBFC)** - working capital, EV multiples, FCF yield, price/sales and price/cash-flow are Not Applicable; gating is by *sector* (not company-name keywords). |
| K | **Pledge** - a pledged-share count disclosed in the shareholding pattern is `verified`; a 0% *inferred* from the absence of a record in NSE's pledge dataset is `needs_review` (INFERRED), never `verified`. |
| L | **Free Float** - 100 − promoter % − locked-in % when locked-in shares are disclosed; otherwise a labelled PROXY (`needs_review`). |
| M | **Discontinued operations** - when EPS is the continuing-operations figure but the statement's profit includes discontinued operations (ITC FY25: Rs 15,016 Cr), the owners' PAT is repaired to the continuing-operations row so PAT and EPS share one perimeter, and the result is `needs_review`. |

### Banking ratios (Sr 58-65) - definitions

Source: `tools/bank_extractor.py` (word-coordinate row reader; every figure is converted to Rs Crore from the unit declared on its own page; a result is produced only when the statements' own identities hold: Schedule 3 Demand + Savings + Term = Total deposits = Balance-sheet Deposits; Total liabilities = Total assets).

| Sr | Ratio | Definition |
|---|---|---|
| 58 | NIM | (Interest Earned − Interest Expended) ÷ average (Cash & RBI balances + Balances with banks + Investments + Advances) × 100; the bank's disclosed NIM is a cross-check - a gap > 0.75 pp makes it `needs_review`. |
| 59 | CASA | (Demand + Savings deposits) ÷ Total deposits (Schedule 3). |
| 60/61 | Gross / Net NPA | the ratio the bank discloses (RBI asset-quality disclosure), never rebuilt from a guessed denominator. |
| 62 | PCR | the Provision Coverage Ratio the bank discloses (labelled when it excludes technical write-offs). |
| 63 | CRAR | Total capital funds ÷ Risk-weighted assets (Basel III table) when both are printed; else the disclosed total CRAR. |
| 64 | Credit-to-Deposit | Advances ÷ Deposits (balance-sheet face). |
| 65 | Cost-to-Income | Operating expenses ÷ (Net interest income + Other income). |

NBFC/HFC (Ind AS) versions: NIM = (Interest income − Finance costs) ÷ average (Loans + Investments); Cost-to-Income = (Employee + Depreciation + Other expenses) ÷ (Total income − Finance costs); CASA and Credit-to-Deposit are not applicable.

## Versioning

`FORMULA_VERSION` is stamped into every stored row (`_metadata.formula_version`), every contract cache key and the document-identity hash of every extraction cache; `_EXTRACTION_LOGIC_VERSION` is bumped with it and is the `ratio_values.extraction_version`. Rows from an older version are recalculated on read (once, per symbol) or returned flagged `stale`. `computed_at` is written explicitly on every upsert. No schema migration is required.

### Cache / version rule
Any change to a label list, row reader, extraction fallback or bank/XBRL path must bump `_EXTRACTION_LOGIC_VERSION` (annual_report_financials) and `EXTRACTION_VERSION` (fundamental_fact_store) in the same commit; a formula / policy change also bumps `FORMULA_VERSION`. The versions are folded into the document-identity hash that keys every extraction and wrapper cache, so stale results can never be served (this was verified the hard way during final validation: results cached before a fix kept an old 'not disclosed' until the version was bumped).
